### MEMBER-002 프로필 생성 - 일반가입
| 항목 | 내용 |
| --- | --- |
| 화면코드 | FL_C_ME_01_03 |
| 도메인 | 공통 / 회원가입 |
| Actor | 시스템(auth-service 내부 호출) |
| 설명 | auth-service로부터 계정 생성 완료 통지를 받아 회원 프로필(닉네임 등)을 생성한다 |
| 비즈니스 룰 | accountId 기준 프로필 레코드 생성, 구매자·판매자 권한 모두 부여, 약관 동의 이력 저장. 본인인증(CI/DI) 관련 필드는 받지 않음 — auth-service 소관 |
| Request | accountId, 이름, 휴대전화번호, 약관동의 목록, (선택) 주소 |
| Response | 생성된 memberId, 프로필 정보 |
| 예외 | 프로필 생성 실패 → auth-service에 실패 응답 반환(계정 생성 롤백 유도) |
| 보안 | [S1·S2·S9] accountId는 auth-service가 발급한 값만 신뢰(서비스 간 호출 인증 필요) / 이름·휴대폰번호 등 저장 시 암호화(S9) / 입력값 검증·바인딩(S1·S2) |
